Sequence#

class pypulseqpp.Sequence(system=None, use_block_cache=True)[source]#

A Pulseq sequence containing events, blocks and definitions.

Parameters:

  • system (Opts, optional) – System limits and rasters. Defaults to the shared system; rasters are recorded in the native sequence.

  • use_block_cache (bool, default True) – Compatibility flag, retained but not used to cache decoded blocks.

system#

The limits the sequence was constructed with.

Type:

Opts | None

num_blocks#

Number of blocks; equivalent to len(seq).

Type:

int

block_durations#

Duration of each block in seconds, keyed by 1-based block index. Assigning an entry changes the stored block duration.

Type:

MutableMapping[int, float]

block_events#

Event IDs of each block, keyed by 1-based block index: delay, RF, gx, gy, gz, ADC and extension. The delay column is zero for Pulseq 1.5. Reading it allocates a dictionary for all blocks.

Type:

dict[int, NDArray[np.int32]]

definitions#

Everything [DEFINITIONS] will carry.

Type:

dict[str, Any]

grad_raster_time#

Gradient raster in seconds.

Type:

float

rf_raster_time#

RF raster in seconds.

Type:

float

adc_raster_time#

ADC dwell raster in seconds.

Type:

float

block_duration_raster#

Raster a block duration is a whole number of, in seconds.

Type:

float

version_major#

Major version of the Pulseq format the sequence is held as. A file older than 1.5 is converted as it is read, so this is what the sequence is rather than what its file declared.

Type:

int

version_minor#

Minor version of the format the sequence is held as.

Type:

int

version_revision#

Revision of the format the sequence is held as.

Type:

int

signature_type#

Hash algorithm of the signature carried by the last file written, or by the last binary file read: 'md5', or None when it had none.

Type:

str | None

signature_file#

Format that file was written in, 'text' or 'bin'.

Type:

str | None

signature_value#

The signature itself.

Type:

str | None

Examples

>>> import pypulseqpp as pp
>>> seq = pp.Sequence(pp.Opts())
>>> seq.add_block(pp.make_trapezoid("x", area=1000, duration=2e-3))
1
>>> seq.add_block(pp.make_delay(1e-3))
2
>>> seq.num_blocks, round(seq.duration()[0], 6)
(2, 0.003)

Blocks#

add_block

Append one block playing events.

set_block

Write events over the block at index, 1-based.

get_block

Decode a block by its 1-based index.

find_block_by_time

Return the 1-based index of the block playing at t seconds.

remove_duplicates

Collapse identical library rows and renumber what points at them.

Definitions and labels#

set_definition

Record key in [DEFINITIONS].

get_definition

Return what key says, or '' if it is not defined.

copy_definitions

Take every definition other_seq carries.

evaluate_labels

Evaluate running label values in block order.

add_trid

Append a block setting TRID to the number label_name is known by.

get_or_create_trid_id

Return the TRID number label_name is known by, naming it if new.

Soft delays#

apply_soft_delay

Set each named soft delay to the value given.

get_default_soft_delay_values

Return what each soft delay stands for if nobody sets it.

Reading and writing#

read

Replace this sequence with the one in file_path.

write

Write Pulseq text and record its signature metadata.

write_binary

Write Pulseq binary, with float32 shape samples.

write_v141

Write Pulseq 1.4.1 text, for an interpreter that predates 1.5.

Waveforms and k-space#

waveforms

Return gradient corners as time (s) over amplitude (Hz/m), per axis.

waveforms_and_times

Return the gradient waveforms, the RF moments and the ADC sampling.

get_gradients

Return physical-axis gradient splines in Hz/m over seconds.

calculate_kspace

Integrate physical-axis gradients with excitation resets and refocusing.

adc_times

Return ADC sample times (s) and per-window frequency (Hz) and phase (rad).

rf_times

Return when the pulses act, and at what frequency and phase.

duration

Return total duration, block count and per-event block counts.

Checks and reports#

check_timing

Check timing, gradient continuity and the stored total duration.

test_report

Return a formatted sequence timing, encoding and gradient report.

test_report_dict

Return timing, encoding and gradient statistics.

calc_rf_power

Return the RF's mean power, peak power, RMS amplitude and energy.

Gradient edits#

flip_grad_axis

Invert every gradient played on axis.

mod_grad_axis

Scale every gradient played on axis by modifier.

Plotting#

plot

Draw the sequence in SeqEyes.

paper_plot

Draw a publication-style diagram of one repetition, with mrsd.
