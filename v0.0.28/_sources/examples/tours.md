# Tours

Standalone examples that build on the Course. Each states its objective and the
Course lessons it assumes.

| Page | What it establishes |
| --- | --- |
| {doc}`/generated/gallery/08-tours/01_multi_echo` | A multi-echo repetition, the echo spacing set by the receiver bandwidth and the gradient ramps, and the number of echoes that fit in the repetition time. |
| {doc}`/generated/gallery/08-tours/02_segmented_epi` | Echo planar readout divided over several shots, and the exchange of scan time for geometric fidelity the shot count makes. |
| {doc}`/generated/gallery/08-tours/03_spiral` | Which of the amplitude, slew-rate and receiver limits determines the duration of a spiral arm, read off the waveform each design produces. |
| {doc}`/generated/gallery/08-tours/04_ramp_sampled_readout` | A readout module sampled through the ramps: the same k-space extent in a shorter lobe, at sampling locations that are not evenly spaced. |
| {doc}`/generated/gallery/08-tours/05_twisting_radial_readout` | A twisting radial arm, stated as a k-space path and solved into a waveform under the gradient limits. |
