_EpiReadout#

class pypulseqpp.sequences.readout.epi._EpiReadout(system, rf, gz=None, gz_reph=None, *, fov, matrix, order=None, etl=None, scheme='linear', acceleration=1, segments=1, partition_acceleration=1, caipi_shift=1, extent=None, te=None, tr=None, oversampling=1.0, readout_bandwidth_hz=500000.0, ramp_sampling=True, flyback=False, spoiling_cycles=0.0, voxel_size_m=None, labels=None, trigger=None)[source]#

Bases: SequenceModule

One RF event followed by an EPI train with a fixed phase-encode pattern.

The scan loop sets the shot origin by scaling prewinders. Blips implement the relative offsets and share the readout ramps; flyback blips instead play in the rewind gaps. TE is measured to the first echo, not the echo that acquires central phase encoding.

rf#

The excitation.

Type:

RfEvent

gz#

Its selection gradient, if one was given.

Type:

GradEvent

gz_reph#

Its rephaser, if one was given.

Type:

GradEvent

gx_pre#

Read prewinder, half a line lobe against the first line’s polarity.

Type:

TrapEvent

gx#

One read lobe per line: alternating polarity for a blipped train, the same lobe every time for a flyback one.

Type:

list of GradEvent

gx_flyback#

The rewind between two lines. flyback only.

Type:

TrapEvent

gy_blips, gz_blips

One phase-encode event per line, or None where no step is asked for, always etl long. A blipped train’s entry carries the second half of the step into the line and the first half of the next out of it; a flyback train’s is the whole step, played in the rewind block after that line, so its last entry is always None. gz_blips is 3D only.

Type:

list

gy_pre, gz_pre

Phase encodes at their largest step, to be scaled per shot. gz_pre is 3D only.

Type:

TrapEvent

gy_rew, gz_rew

The encodes negated, in the block that closes the repetition.

Type:

TrapEvent

gx_spoil#

The lobe that closes the read axis, bridged off the last line.

Type:

GradEvent

adc#

The acquisition window, shared by every line.

Type:

AdcEvent

shot_labels#

SET counters on the prewinder block, one per name in labels. The loop writes the shot’s origin into them. Always a tuple, however many names there are, because the loop splats it.

Type:

tuple of LabelEvent

line_labels#

Per line, the INC counters that step from the previous line to this one – the ordering, expressed as labels. Empty for the first line, which the SET already placed.

Type:

tuple of tuple of LabelEvent

order#

(etl, 2) integer (ky, kz) offsets from the shot’s origin.

Type:

numpy.ndarray

wait_te#

Present only when a TE longer than the minimum was asked for.

Type:

DelayEvent

wait_tr#

Present only when a TR longer than the minimum was asked for.

Type:

DelayEvent

etl#

Lines per repetition.

Type:

int

esp#

Echo spacing (s).

Type:

float

echo_times#

Each line’s echo time (s) from the excitation isodelay.

Type:

numpy.ndarray

echo_time#

The first line’s, which is what te sets.

Type:

float

bandwidth_hz#

Achieved ADC sampling rate (Hz).

Type:

float

n_samples#

Samples per line.

Type:

int

delta_kx#

Read-axis k-space step (1/m).

Type:

float

blip_span#

Time one phase-encode step takes (s). It is paid out of the read ramps.

Type:

float

Parameters:

  • system (pypulseq.Opts) – System limits.

  • rf (RfEvent) – The pulse that opens the repetition. A refocusing pulse builds the readout half of a spin-echo EPI.

  • gz (GradEvent, optional) – A selection gradient played in the same block as rf.

  • gz_reph (GradEvent, optional) – The rephaser that unwinds gz.

  • fov (float or sequence of float) – Field of view (m), per encoded axis, readout first.

  • matrix (int or sequence of int) – Matrix size, per encoded axis.

  • order (array_like, optional) – (etl,) or (etl, 2) integer offsets from the shot’s origin, one row per line. Supplying one silences the generator arguments below; the default asks calc_epi_order() for a train.

  • etl (int, optional) – Lines per repetition. Defaults to what one shot of the requested scheme needs to cross the phase-encode matrix.

  • scheme ({'linear', 'caipi', 'zigzag'}, optional) – Which built-in ordering to generate. See calc_epi_order().

  • acceleration – Passed to calc_epi_order().

  • segments – Passed to calc_epi_order().

  • partition_acceleration – Passed to calc_epi_order().

  • caipi_shift – Passed to calc_epi_order().

  • extent – Passed to calc_epi_order().

  • te (float, optional) – Excitation isodelay to the first echo (s). None is as short as possible; every other echo follows at esp intervals, and echo_times lists them.

  • tr (float, optional) – Repetition time (s), over the whole module.

  • oversampling (float, optional) – Read oversampling.

  • readout_bandwidth_hz (float, optional) – Requested ADC sampling rate (Hz). bandwidth_hz reports the achieved raster-compatible rate.

  • ramp_sampling (bool, optional) – Sample across the read ramps as well as the plateau, which is what makes the echo spacing short. Turn it off for a rectangular window at the cost of a longer train.

  • flyback (bool, optional) – Read every line in the same direction, rewinding between them, instead of alternating polarity. It costs a rewind per line and buys away the odd-even inconsistency that a bipolar train leaves behind.

  • spoiling_cycles (float, optional) – Read-axis spoiling at the end of the repetition, in cycles across voxel_size_m.

  • voxel_size_m (float, optional) – Length the spoiling is counted over (m). The read resolution by default.

  • labels (sequence of str, optional) – Counters for the encoded axes, phase encode first. Two names for a 3D train, one for 2D.

  • trigger (event, optional) – A trigger or digital output armed on the prewinder block.

Raises:

ValueError – If a count is out of range, order is the wrong shape or steps outside the matrix, labels does not name one counter per encoded axis, or the requested TE or TR is shorter than the train can achieve.
