API object index

API object index#

The stub page of every documented object. The API pages carry the same object lists as tables, each entry linking the stub this page writes; writing them here keeps them out of the toctree the sidebar is built from.

SequenceApp

A complete sequence, designed from a prescription and played one repetition at a time.

ProtocolParameter

One prescribed parameter, as init_sequence declares and documents it.

run

Run a sequence script's main from the command line.

make_adc

Create an ADC readout event.

make_delay

Creates a delay event.

make_digital_output_pulse

Create a digital output pulse event a.k.a.

make_label

Create a label event.

make_rf_shim

Create complex per-transmit-channel weights for a block's RF envelope.

make_rotation

Create a rotation extension event for a block's gradients.

make_soft_delay

Create a soft delay extension event for dynamic timing adjustment.

make_trigger

Create a trigger halt event for a synchronization with an external signal from a given channel with an optional

align

Sets delays of the objects within the block to achieve the desired alignment of the objects in the block.

block_to_events

Split a block into its events, or pass events through unchanged.

calc_absolute_offsets

Return an RF or ADC event's frequency and phase offsets with its ppm offsets resolved.

calc_duration

Calculate the duration of an event or block.

rotate

Rotates the corresponding gradient(s) about the given axis by the specified amount.

get_supported_labels

enable_trace

Enable tracing where sequence events and blocks were created.

disable_trace

Disabling tracing where sequence events and blocks were created.

interoperating

Wrap a callable with recursive event conversion.

convert

Convert a PyPulseq event to a compiled event; return other objects unchanged.

as_namespace

Convert a compiled event to a PyPulseq-compatible SimpleNamespace.

make_arbitrary_grad

Create a gradient from amplitudes sampled at raster centres.

make_crusher

Create a crusher winding dephasing_cycles of phase across a voxel.

make_extended_trapezoid

Create a gradient by specifying a set of points (amplitudes) at specified time points(times) at a given channel with given system limits.

make_extended_trapezoid_area

Make the shortest possible extended trapezoid for given area and gradient start and end point.

make_hexagon_gradient_area

Design a minimum-duration gradient with specified area and endpoint amplitudes.

make_phase_blip

Create a phase-encode blip of area steps / fov for an echo train.

make_phase_encoding

Create a positive phase-encode template of area 1 / (2 * resolution).

make_trapezoid

Create a trapezoidal gradient event.

make_wave_gradients

Create self-balanced wave-encoding gradient events for one readout flat top.

add_gradients

Returns the superposition of several gradients.

calc_ramp

Join the points k0 and k_end in three-dimensional k-space in minimal time, observing the gradient and slew limits (max_grad and max_slew respectively), and the gradient strength G0 before k0[:, 1] and Gend after k_end[:, 1].

concatenate_gradients

Concatenate gradients on one channel without modifying the inputs.

points_to_waveform

1D interpolate amplitude values amplitudes at time indices times as per the gradient raster time grad_raster_time to generate a gradient waveform.

rotate_3d

Rotate and sum gradient projections onto the output axes.

scale_grad

Scales the gradient with the scalar.

split_gradient

Splits a trapezoidal gradient into slew up, flat top and slew down.

split_gradient_at

Splits a trapezoidal gradient into two extended trapezoids defined by the cut line.

read

Read a Pulseq file into a sequence whose system describes what is in it.

read_chain

Read a sequence file and every file its NextSequence definitions name, in play order.

write

Write a sequence as Pulseq text or binary.

SequenceLibraries

A sequence's block table and every library it holds, as read-only arrays.

Shape

One row of the shape library, as a file writes it.

SequenceModule

A reusable block layout with named, mutable event templates.

RfModule

Sequence module with off-resonance simulation of an individual RF pulse.

NonSelectiveExcitation

Rectangular RF excitation without a selection gradient.

NonSelectiveRefocusing

Rectangular refocusing pulse between two identical crushers.

SpatialSelectiveExcitation

SLR excitation with a selection gradient and optional rephasing.

SpatialSelectiveRefocusing

SLR refocusing with matched crushers joined to the selection plateau.

SpatialSelective2DExcitation

Small-tip spiral excitation selective in two dimensions.

FrequencySelectiveExcitation

SLR excitation of a spectral band without spatial selection.

SpspExcitation

Spectral-spatial excitation using SLR subpulses on an alternating gradient.

SmsExcitation

SLR slice excitation modulated into simultaneous spectral bands.

MultibandExcitation

Non-spatially-selective RF excitation with off-resonance sidebands.

InversionPreparation

Non-selective adiabatic inversion, followed by an optional crusher.

BlochSiegertPreparation

Off-resonance Fermi pulse for Bloch-Siegert B1 mapping.

DiffusionPreparation

Non-selective diffusion preparation with hard tip-down and storage pulses.

FatSaturation

SLR fat saturation with a three-axis spoiler and optional spatial selection.

IhMtPreparation

Simultaneous dual-offset saturation for ihMT measurements.

MtPreparation

Off-resonance SLR saturation followed by an optional spoiler.

OffResonanceSaturation

Repeat one off-resonance pulse, followed by an optional three-axis spoiler.

T1T2Preparation

T2 preparation with storage on -z to initiate T1 recovery.

T2Preparation

Adiabatic T2 preparation with tip-down, refocusing and storage pulses.

LineReadout2D

One Cartesian line, frequency-encoded along x and phase-encoded along y.

LineReadout3D

One Cartesian line of a 3D slab, phase-encoded along y and z.

EpiReadout2D

A single- or multi-shot EPI train, frequency-encoded along x.

EpiReadout3D

A slab-selective EPI train, phase-encoded along y and partition-encoded along z.

FseReadout2D

A slice-selective CPMG train, frequency-encoded along x.

FseReadout3D

Single-slab CPMG train, phase-encoded along y and partition-encoded along z.

BssfpReadout2D

Slice-selective balanced SSFP, phase-encoded along y.

BssfpReadout3D

Slab-selective balanced SSFP, encoded along y and z.

PropellerReadout2D

EPI blades turned about the centre of k-space, as a 2D PROPELLER set.

PropellerStackReadout

A stack of 2D PROPELLER blade sets, partition-encoded along z.

NonCartesianReadout

A solved interleaf with its prewinder, rewinder and repetition-time budget.

RadialReadout2D

A full radial spoke through the centre of a plane.

RadialStackReadout

Radial spokes in-plane with Cartesian partitions along z, a stack of stars.

RadialProjectionReadout

Radial spokes for a spherical projection acquisition.

SpiralReadout2D

One spiral arm in a plane.

SpiralStackReadout

Spiral arms in-plane, Cartesian partitions along z.

SpiralProjectionReadout

Spiral arms turned over a sphere.

SpiralNavigator

Three orthogonal thick-slab spiral navigators.

RosetteReadout2D

One multi-petal rosette interleaf in a plane.

RosetteStackReadout

Rosette petals in-plane, Cartesian partitions along z.

RosetteProjectionReadout

Rosette petals turned over a sphere.

ZteReadout

Continuous-gradient ZTE shell, including its initial and final ramps.

NonCartesianGradient

One canonical non-Cartesian base interleaf, independent of its acquisition schedule.

Arbitrary

Base interleaf from a caller-supplied 2D or 3D k-space path.

Spiral

Constant-, variable- or dual-density spiral base interleaf.

Rosette

Multi-petal rosette base interleaf, starting and ending at k = 0.

plot

Open seq in the SeqEyes viewer.

paper_plot

Draw a publication diagram of seq.

SAMPLING

Colormap objects based on lookup tables using linear segments.

MAGNITUDE

Colormap objects based on lookup tables using linear segments.

SIGNED

Colormap objects based on lookup tables using linear segments.

plot_kspace

Plot the ADC sampling locations in k-space.

plot_rf

Draw an RF pulse's |B1| envelope beside the profile it produces.

make_adiabatic_pulse

Construct an adiabatic RF pulse, a frequency sweep insensitive to B1.

make_arbitrary_rf

Create an RF pulse with the given pulse shape.

make_block_pulse

Create a block (RECT or hard) pulse.

make_gauss_pulse

Create a [optionally slice selective] Gauss pulse.

make_half_passages

Build the adiabatic half-passage pair that tips magnetization down and back.

make_sinc_pulse

Creates a radio-frequency sinc pulse event and optionally accompanying slice select and slice select rephasing trapezoidal gradient events.

make_slr_pulse

Design an RF pulse using the Shinnar-Le Roux algorithm.

make_recursive_slr_pulses

Design SLR pulses that each excite the same transverse magnetisation.

make_sms_pulse

Modulate one RF pulse into equispaced spectral bands.

make_spsp_pulse

Design a spectral-spatial pulse on an alternating slice gradient.

make_2d_selective_pulse

Design a small-tip 2D-selective pulse on a spiral excitation trajectory.

make_gslider_pulse

Design a gSlider slab pulse with subslice at subslice_phase.

make_hadamard_pulse

Design a slab pulse whose sub-bands are signed by row row of a Hadamard matrix.

make_pins_pulse

Design a PINS pulse exciting a slice every slice_separation along z.

make_b1_selective_pulse

Design a B1-selective RF pulse, excited only where the transmit amplitude lies in a band.

make_b1_gslider_pulse

Design a B1-selective gSlider pulse with one B1 sub-band at subslice_phase.

make_b1_hadamard_pulse

Design a B1-selective pulse whose B1 sub-bands are signed by a Hadamard row.

make_bloch_siegert_pulse

Design an adiabatic Bloch-Siegert encoding pulse.

make_ptx_pulse

Make a dynamic pTx pulse from one waveform per transmit channel.

split_ptx_pulse

Return a pulse's waveforms, one row per transmit channel, in Hz.

calc_rf_shim

Return per-channel weights whose combined B1 field has magnitude target.

make_spokes_pulse

Design a spokes pTx pulse, exciting one slice at several in-plane k positions.

calc_rf_bandwidth

Estimate RF bandwidth from the envelope's Fourier magnitude.

calc_rf_center

Calculate the time point of the effective rotation calculated as the peak of the radio-frequency amplitude for the shaped pulses and the center of the pulse for the block pulses.

calc_rf_power

Return an RF event's energy, peak power and RMS amplitude, as MATLAB Pulseq's calcRfPower.

sim_bloch

Simulate the Bloch equation without relaxation, in hard-pulse steps.

sim_rf

Simulate an RF pulse versus off-resonance without relaxation.

check_max_grad

Check the peak gradient amplitude against max_grad.

check_max_slew

Check the within-block slew rate against max_slew.

check_grad_continuity

Check gradient amplitude continuity across block boundaries.

check_mech_resonance

Check the gradient amplitude spectrum against forbidden gradient bands.

mech_resonance_spectrum

Return the gradient amplitude spectrum of one window, per physical axis.

read_forbidden_bands

Read forbidden bands from a Siemens .asc hardware description.

ForbiddenBand

A forbidden gradient band, a frequency range on one physical axis.

check_pns

Check peripheral nerve stimulation against a SAFE or chronaxie model.

read_safe_model

Read a SAFE nerve model from a Siemens .asc hardware description.

ChronaxieModel

Rheobase-chronaxie nerve model, one coefficient set for every physical axis.

check_sar

Check window-averaged local and global SAR against their limits.

read_vops

Read VOPs and a global SAR matrix from a .mat or .npz file.

example_vops

Build a synthetic VOP model, for demonstrations and tests only.

VopModel

Virtual observation points, and an optional global SAR matrix.

make_cartesian_axis_sampling

Select the acquired views of one Cartesian encoding axis.

make_cartesian_plane_sampling

Select the acquired (line, partition) views of a Cartesian ky-kz plane.

make_caipirinha_mask

Generate a CAIPIRINHA lattice sampling mask.

make_poisson_disc_mask

Generate a variable-density Poisson-disc Cartesian sampling mask.

make_random_mask

Generate a uniform-random Cartesian sampling mask with a calibration region.

make_traversal_order

Return the order in which a loop visits n positions.

make_linear_order

Echo-train ordering of Cartesian views in linear (raster) order.

make_centric_order

Echo-train ordering of Cartesian views in centric order.

make_radial_order

Echo-train ordering of Cartesian views in centre-out radial order.

make_radial_adaptive_order

Echo-train ordering of Cartesian views in radial order about a target echo.

make_shuffling_order

Echo-train ordering of Cartesian views with random echo positions.

make_epi_shot_offsets

Return the phase-encoding offsets of one EPI shot, relative to its first echo.

calc_uniform_angles

Return equally spaced rotations in the half-open interval [0, span).

calc_golden_angles

Return golden-angle rotations in radians, accumulated modulo 2*pi.

calc_tiny_golden_angles

Return tiny-golden rotations with increment pi / (phi + index - 1).

calc_raga_angles

Return rational approximate golden-angle (RAGA) rotations.

calc_projection_shell

Return a pole-to-pole base shell and z-axis rotations for each shot.

make_rf_spoiling_schedule

Return quadratic RF-spoiling phases in radians.

make_phase_cycling_schedule

Repeat a phase cycle, reducing each entry modulo 2*pi.

make_traps_schedule

Return a variable refocusing flip-angle schedule in radians.
