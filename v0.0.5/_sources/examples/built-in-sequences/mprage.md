# MPRAGE

An inversion, an inversion time, and then a spoiled gradient-echo train that
acquires one partition. The T1 contrast is determined by the inversion-recovery
time at which the central k-space views are acquired.

| Example | Scope |
| --- | --- |
| {doc}`/generated/gallery/12-mprage/mprage3D_sequence` | Cartesian phase-encode lines of one partition per inversion. |
| {doc}`/generated/gallery/12-mprage/mprage_stack_of_stars3D_sequence` | Radial spokes of one partition per inversion. |
| {doc}`/generated/gallery/12-mprage/mprage_stack_of_spirals3D_sequence` | Spiral interleaves of one partition per inversion. |
