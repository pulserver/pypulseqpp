# Guides

Task-oriented procedures for sequence construction, analysis and constraint
checking. Conceptual background is
in {doc}`../explanations/index`, and the exhaustive interface semantics in
{doc}`../api/index`.

| Guide | Task |
| --- | --- |
| {doc}`first-sequence` | Build a two-dimensional spoiled gradient echo from Pulseq events, check timing, and write a `.seq` file. |
| {doc}`analysing-a-sequence` | Inspect structure, encoding indices, timing, waveforms, k-space, and figures. |
| {doc}`checking-constraints` | Run gradient, PNS, mechanical-resonance, and SAR checks and interpret their reports. |
| {doc}`custom-module` | Assemble modules into a reusable sequence application. |
| {doc}`command-line` | Run a shipped or custom sequence from a shell. |
