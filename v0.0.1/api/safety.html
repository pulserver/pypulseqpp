Hardware safety

Hardware safety#

Safety checks inspect what the complete sequence asks of the scanner. They apply block rotations, evaluate all three physical axes together, and may use either the sequence’s own limits or a different pypulseqpp.Opts.

check_max_grad() checks the peak played gradient amplitude; check_max_slew() checks slew within blocks; and check_grad_continuity() checks the transitions between blocks and the end of the sequence.

check_mech_resonance() slides a Hann-tapered window along each physical axis and compares the amplitude spectrum of every window with the forbidden bands that guard that axis. Bands come as ForbiddenBand entries or from a vendor table through read_forbidden_bands(). The transform is MKL’s when the optional mkl extra is installed, and the compiled-in pocketfft otherwise.

check_pns() runs a nerve model over the slew of each physical axis and compares the root-sum-square response with its threshold. The model is either SAFE, as upstream PyPulseq computes it, from a description shaped like upstream’s safe_example_hw() or a Siemens .asc file read by read_safe_model(); or a rheobase-chronaxie ChronaxieModel.

check_sar() averages SAR from virtual observation points over each real repetition, and compares the worst repetition’s largest VOP SAR with a local limit and, given a global matrix, its global SAR with a global limit. VOPs come as a VopModel, read from a .mat or .npz file by read_vops(), or from example_vops(), a synthetic model for demonstration only. RF power in Pulseq’s Hz units is pypulseqpp.calc_rf_power() for one pulse and Sequence.calc_rf_power for a sequence.

These checks estimate what the gradients and RF ask of the hardware and of the subject. They are not a complete scanner or patient-safety assessment.

check_max_grad

Return whether every gradient is within the amplitude limit.

check_max_slew

Return whether every gradient is within the slew limit, within a block.

check_grad_continuity

Return whether each gradient carries on from the block before it.

check_mech_resonance

Return whether no window drives a forbidden band above its threshold.

read_forbidden_bands

Read forbidden bands from a vendor table.

ForbiddenBand

A frequency range a physical gradient axis must not be driven in.

check_pns

Return whether the nerve response stays below threshold throughout.

read_safe_model

Read a SAFE nerve model from a Siemens .asc hardware description.

ChronaxieModel

Rheobase-chronaxie nerve model, one coefficient set for every physical axis.

check_sar

Return whether no repetition exceeds the local and global SAR limits.

read_vops

Read VOPs and a global SAR matrix from a .mat or .npz file.

example_vops

Build a synthetic VOP model, for demonstrations and tests only.

VopModel

Virtual observation points, and an optional global SAR matrix.
